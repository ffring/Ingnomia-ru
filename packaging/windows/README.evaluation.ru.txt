NoesisGUI без лицензии
----------------------
Интерфейс игры построен на библиотеке NoesisGUI. Эта копия собрана без
лицензионного ключа Noesis, в ознакомительном режиме. Через некоторое время
после запуска NoesisGUI показывает собственное предупреждение об этом. Это
ограничение библиотеки, а не ошибка перевода.
